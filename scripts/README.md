# hft02 receiver and diagnostic scripts

These scripts and the root configs preserve the operational hft02 workspace layout. They complement the historical archive in [docs/gnss_sdr_experiments](../docs/gnss_sdr_experiments/EXPERIMENT_RESULTS.md). Paths embedded in configs/manifests describe that machine; they are not generic receiver setup defaults.

The standalone epoch harness uses existing local GNSS-SDR source copies, saved observables and experimental assistance XML. Those recordings/source copies and compiled binaries are not included here. See the [14052 report](../docs/gnss_sdr_experiments/RX1H_14052_BOOTSTRAP_RESULTS.md) for inputs, results, restrictions and the native-confirmation plan. No dependency installation or hardware operation is needed to read this archive.
