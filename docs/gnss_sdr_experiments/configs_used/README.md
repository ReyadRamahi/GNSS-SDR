# Configs Used

This folder collects GNSS-SDR config files by purpose instead of leaving all `.conf` files flat in one place.

## Subfolders

- `baseline/`
  - older general Lime baseline/reference configs
- `agnss/`
  - Lime configs that explicitly use assistance XML
- `f9t_lime_current/`
  - the current focused configs for the active F9T + Lime debugging work
- `rtl_reference/`
  - RTL-SDR reference configs that proved the pipeline can decode GPS
- `sweeps/`
  - config families used for parameter sweeps such as sample-rate comparisons

See `CONFIG_INDEX.md` for a short description of the important files.
