# Lime Sweep Logs

This folder keeps the broader Lime parameter-search history.

## Subfolders

- `v1/`
  - earlier threshold and loop-parameter sweep runs
- `v2/`
  - intermediate sweep runs around sample-rate and filter choices
- `v3/`
  - later sweep runs around sample rate, taps, band limits, and AGC state

These folders are useful for understanding how the project converged on the current Lime direction:

- lower threshold
- `2 Msps`
- `101` taps
- wider L1 filter
- AGC disabled
