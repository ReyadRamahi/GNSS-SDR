# Assist Artifacts

This folder groups assistance-related files by where they came from.

## Subfolders

- `f9t_latest/`
  - current local F9T snapshot used by the active Lime experiments
  - `README_CURRENT_XML.txt` contains capture time, source, and PRN count
- `f9t_tcp_reference/`
  - older assistance XML produced from the historical `hft09` TCP workflow
- `rtl_harvested/`
  - assistance XML harvested from successful RTL-SDR runs
- `raw/`
  - raw assistance-related source inputs kept for reference

Current active work should prefer `f9t_latest/`.
