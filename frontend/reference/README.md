# Reference assets

`satellite.glb` is the optional satellite model retained from the original frontend. It is not bundled or requested by the current app, whose satellites are procedural Three.js meshes.

For an experiment with model loading, copy it into `frontend/public/models/` and load that URL using Three.js or Drei. See [the frontend learning guide](../README.md) and [runtime asset notes](../public/ASSETS.md).
